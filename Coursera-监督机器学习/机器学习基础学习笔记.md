## 一、机器学习分类体系

从数据是否包含**标签（Label / Target）**的角度，机器学习可分为：

```
机器学习
├── 有监督学习（Supervised Learning）→ 数据含标签 y
│   ├── 回归（Regression）→ 输出为连续数值
│   │   └── 线性回归、多项式回归、岭回归、Lasso 等
│   └── 分类（Classification）→ 输出为离散类别
│       └── 逻辑回归、SVM、决策树、朴素贝叶斯、神经网络 等
├── 无监督学习（Unsupervised Learning）→ 数据无标签
│   ├── 聚类 → K-Means、DBSCAN
│   └── 降维 → PCA、t-SNE
└── 其他 → 强化学习、半监督学习、自监督学习
```

### 有监督学习 vs 无监督学习

| 维度 | 有监督学习 | 无监督学习 |
|------|-----------|-----------|
| 数据 | 输入 X + 标签 y | 仅有输入 X |
| 目标 | 学习 X→y 的映射关系 | 发现数据内在结构 |
| 典型任务 | 房价预测、垃圾邮件识别 | 客户分群、数据降维 |

## 二、线性回归（Linear Regression）

### 核心思想
通过拟合一条直线（或超平面），建立输入特征与连续输出之间的线性关系。

### 假设函数
$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_n x_n$$

### 代价函数（Cost Function）
使用**均方误差（Mean Squared Error, MSE）**：
$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2$$

> 其中 $m$ 为样本数量，除以 $2m$ 是为了求导后系数更简洁。

---

## 三、梯度下降法（Gradient Descent）

### 核心思想
沿着损失函数梯度的**反方向**迭代更新参数，逐步逼近最优解。

### 参数更新公式
$$\theta_j := \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$$

### 三种变体

| 变体 | 每次更新使用的样本 | 特点 |
|------|------------------|------|
| **批量梯度下降（Batch GD）** | 全部 $m$ 个样本 | 稳定但计算量大 |
| **随机梯度下降（SGD）** | 1 个样本 | 速度快但波动大 |
| **小批量梯度下降（Mini-batch GD）** | $b$ 个样本（如 32、64、128）| **最常用**，平衡速度与稳定性 |

### 学习率（Learning Rate, $\alpha$）

- **过大**：参数更新步幅过大 → 震荡、不收敛，甚至发散
- **过小**：参数更新步幅过小 → 收敛极慢，可能陷入局部最优
- **常用策略**：**学习率衰减（Learning Rate Decay）**——训练初期用较大学习率快速接近最优，后期逐渐减小以精细收敛

## 四、特征缩放（Feature Scaling）

### 目的
消除不同特征之间的**量级差异**，使梯度下降更快收敛。

> 例如：房屋面积（$10^2$ 量级）与房间数量（$10^0$ 量级）同时存在时，未缩放的梯度下降会沿狭长椭圆路径缓慢收敛。

### 常用方法

| 方法 | 公式 | 结果范围 | 适用场景 |
|------|------|---------|---------|
| **归一化（Normalization / Min-Max Scaling）** | $x' = \frac{x - \min(x)}{\max(x) - \min(x)}$ | $[0, 1]$ | 数据分布无明显异常值 |
| **标准化（Standardization / Z-score）** | $x' = \frac{x - \mu}{\sigma}$ | 均值为 0，标准差为 1 | 数据存在异常值或分布未知（**更常用**） |

## 五、逻辑回归（Logistic Regression）

> ⚠️ **注意**：虽然名字中有"回归"，但逻辑回归本质是**分类算法**。

### 假设函数（预测函数）
使用 **Sigmoid 函数**将线性输出映射到 $(0, 1)$ 区间，解释为概率：

$$h_\theta(x) = \sigma(z) = \frac{1}{1 + e^{-z}}, \quad z = \theta^T x$$

### 决策边界
通常以概率阈值 $0.5$ 进行二分类：
- $h_\theta(x) \geq 0.5$ → 预测为类别 1
- $h_\theta(x) < 0.5$ → 预测为类别 0

### 代价函数：为什么不用 MSE？

| | 线性回归 | 逻辑回归 |
|--|---------|---------|
| 输出 | 连续值 $\hat{y}$ | 概率 $\hat{y} \in (0,1)$ |
| 假设函数 | $h(x) = \theta^T x$ | $h(x) = \sigma(\theta^T x)$ |
| 代价函数 | **均方误差（MSE）** | **对数损失 / 交叉熵（Cross-Entropy）** |
| 凸性 | MSE 是凸函数 | 若用 MSE，Sigmoid 的非线性会导致代价函数**非凸**，存在多个局部最优；交叉熵是凸函数，保证梯度下降收敛到**全局最优** |

### 交叉熵损失（Log Loss）
$$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(h_\theta(x^{(i)})) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]$$

## 六、过拟合（Overfitting）与正则化

### 过拟合 vs 欠拟合

| | 欠拟合（Underfitting） | 过拟合（Overfitting） |
|--|---------------------|---------------------|
| 原因 | 模型太简单，未学到数据规律 | 模型太复杂，"记住"了训练数据中的噪声 |
| 偏差-方差 | **高偏差（High Bias）** | **高方差（High Variance）** |
| 训练集表现 | 差 | 很好 |
| 测试集表现 | 差 | 差 |
| 解决方向 | 增加模型复杂度 | 降低模型复杂度或增加数据 |

### 解决过拟合的四种方法

#### 1. 增加样本数量
数据量越大，模型越难"死记硬背"，被迫学习泛化规律。

#### 2. 选择合适的特征
- **特征选择（Feature Selection）**：手动或自动筛选最相关的特征
- **降维（Dimensionality Reduction）**：如 PCA（主成分分析），将高维数据映射到低维空间

#### 3. 正则化成本函数（Regularization）
在代价函数中加入对参数大小的惩罚项，防止权重过大导致模型过于复杂。

| 正则化类型 | 惩罚项 | 特点 |
|-----------|--------|------|
| **L1 正则化（Lasso）** | $\lambda \sum \|\theta_j\|$ | 倾向于产生**稀疏解**（部分权重变为 0），可用于**自动特征选择** |
| **L2 正则化（Ridge）** | $\lambda \sum \theta_j^2$ | 惩罚大权重，使权重分布更**平滑**（更常用） |

- **正则化参数 $\lambda$**：
  - $\lambda$ 过大 → 惩罚过强 → **欠拟合**
  - $\lambda$ 过小 → 惩罚不足 → 无法抑制过拟合

#### 4. 其他常用手段
- **早停（Early Stopping）**：在验证集误差开始上升前停止训练
- **Dropout**（神经网络中）：随机丢弃部分神经元，防止共适应
- **集成方法**：如随机森林（Random Forest）、梯度提升（Gradient Boosting）

## 七、模型评估与诊断

### 数据集划分
```
原始数据
├── 训练集（Training Set）→ 训练模型参数
├── 验证集（Validation Set）→ 调参、选择模型、确定正则化强度
└── 测试集（Test Set）→ 最终评估模型泛化能力（仅使用一次）
```

### 学习曲线（Learning Curves）
通过绘制**训练误差**和**验证误差**随训练样本量变化的曲线，判断模型状态：
- 两条曲线都高且接近 → **欠拟合**（高偏差）→ 需要更复杂的模型
- 训练误差低，验证误差高且差距大 → **过拟合**（高方差）→ 需要更多数据或正则化

### 分类任务评估指标

| 指标 | 公式/定义 | 适用场景 |
|------|----------|---------|
| **准确率（Accuracy）** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 类别均衡时 |
| **精确率（Precision）** | $\frac{TP}{TP+FP}$ | 关注"预测为正的结果中有多少是真的"（如垃圾邮件过滤） |
| **召回率（Recall）** | $\frac{TP}{TP+FN}$ | 关注"真正的正例中有多少被找出来了"（如疾病筛查） |
| **F1 分数** | $2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}$ | 精确率和召回率的调和平均，类别不平衡时更可靠 |

> $TP$：真正例，$TN$：真负例，$FP$：假正例，$FN$：假负例

## 八、关键概念速查表

| 概念 | 一句话解释 |
|------|-----------|
| **标签（Label）** | 有监督学习中，每个样本对应的正确输出/答案 |
| **特征（Feature）** | 用于预测标签的输入变量 |
| **假设函数** | 模型对输入到输出的映射关系的数学表达 |
| **代价函数** | 衡量模型预测值与真实值差距的函数，训练目标是最小化它 |
| **梯度** | 代价函数对各参数的偏导数，指示参数更新的方向 |
| **学习率** | 控制每次参数更新步幅的超参数 |
| **特征缩放** | 将不同特征统一到相近数量级，加速梯度下降 |
| **Sigmoid** | 将任意实数映射到 $(0,1)$ 的 S 型函数 |
| **交叉熵** | 衡量两个概率分布差异的损失函数，逻辑回归的标准代价函数 |
| **正则化** | 在代价函数中惩罚大权重，防止模型过拟合 |
| **L1 / L2** | 两种正则化方式，L1 产生稀疏解，L2 产生平滑解 |
| **偏差-方差权衡** | 模型复杂度与泛化能力之间的核心矛盾 |
