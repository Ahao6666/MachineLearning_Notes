## 第一周：神经网络基础

### 1.1 从生物神经元到神经网络

课程从生物神经元与大脑的工作机制引入，逐步过渡到**人工神经网络（Artificial Neural Network, ANN）**模型。核心思想是通过多层非线性变换，让网络自动学习数据的层次化特征表示。

### 1.2 使用 TensorFlow 构建神经网络

需要掌握使用 TensorFlow/Keras 构建基础神经网络的基本流程：

```python
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(units=25, activation='relu'),   # 隐藏层1
    Dense(units=15, activation='relu'),   # 隐藏层2
    Dense(units=1, activation='linear')    # 输出层
])
```

**关键要点：**
- **隐藏层**通常使用 **ReLU（Rectified Linear Unit）** 作为激活函数，缓解梯度消失问题，加速收敛。
- **输出层**的激活函数取决于任务类型：
  - 回归任务：`linear`（线性激活，即无激活函数）
  - 二分类任务：`sigmoid`
  - 多分类任务：`softmax`

## 第二周：神经网络训练

### 2.1 模型编译与训练

在使用 TensorFlow 训练时，注意代码的前后逻辑关系：

```python
model.compile(
    loss=tf.keras.losses.BinaryCrossentropy(from_logits=True),
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001)
)
```

**`from_logits=True` 的含义：**
- 当输出层使用**线性激活**（不经过 sigmoid/softmax）时，模型输出的是"原始分数"（logits）。
- 设置 `from_logits=True` 后，损失函数会在内部自动应用 sigmoid/softmax 并计算交叉熵。
- **优点**：数值稳定性更好，避免了单独计算激活函数时的数值溢出或下溢问题。

### 2.2 Softmax 回归与多输出

**Softmax** 是 sigmoid 在多分类场景下的推广，将任意实数向量映射为概率分布（所有输出之和为1）。

**重要区分：多分类（Multi-class）vs 多标签（Multi-label）**

| 类型 | 定义 | 输出层设计 | 损失函数 |
|------|------|-----------|---------|
| **多分类** | 每个样本属于**且仅属于**一个类别 | 单个 Softmax 层，输出维度 = 类别数 | `CategoricalCrossentropy` |
| **多标签** | 每个样本可以同时属于**多个类别** | 多个独立的 Sigmoid 输出单元 | `BinaryCrossentropy` |

### 2.3 反向传播（Backpropagation）

反向传播是训练神经网络的核心算法，基于**链式法则（Chain Rule）**高效计算损失函数对各层参数的梯度，从而通过梯度下降更新权重。

**核心流程：**
1. **前向传播**：计算每一层的输出，直至得到预测值和损失
2. **反向传播**：从输出层开始，逐层向后计算梯度
3. **参数更新**：使用优化器（如 Adam、SGD）根据梯度更新权重

## 第三周：应用机器学习的建议

### 3.1 机器学习诊断

**诊断（Diagnostics）**的目标是判断：为了提升模型性能，应该优先改进哪些方面（获取更多数据？增加特征？调整模型结构？）。

### 3.2 数据集划分

将数据集划分为三个互斥子集：

| 子集 | 占比 | 作用 |
|------|------|------|
| **训练集（Training Set）** | 60% | 用于训练模型参数 |
| **交叉验证集（Cross Validation Set）** | 20% | 又称**验证集（Validation Set）**或**开发集（Dev Set）**，用于**模型选择**、**超参数调优**和**早停（Early Stopping）** |
| **测试集（Test Set）** | 20% | 仅用于**最终评估**，反映模型在未见数据上的泛化能力 |

> **注意**：验证集上的结果不能作为最终性能报告，否则会造成信息泄露（相当于间接用测试集调参）。

### 3.3 模型评估与选择

**核心思想**：通过比较不同复杂度模型在训练集和验证集上的表现，选择最优模型。

**多项式回归评估**：尝试不同阶数的多项式特征，分别计算训练集和验证集的 MSE，选择验证集 MSE 最小的阶数。注意：验证集的特征变换必须使用训练集拟合的 `PolynomialFeatures` 和 `StandardScaler`，防止数据泄露。

**神经网络评估**：构建不同结构的网络（如不同层数/单元数），在训练集上训练后，比较训练集和验证集的误差，选择验证误差最小的模型。仅在最终选定的模型上使用测试集评估。

**分类任务评估**：对于二分类，使用逻辑回归输出 logits，经 sigmoid 转换为概率后，以 0.5 为阈值计算分类错误率。

### 3.4 偏差（Bias）与方差（Variance）诊断

通过比较训练集和验证集的代价函数，判断模型的拟合状态：

| 训练集误差 | 验证集误差 | 诊断 | 说明 |
|-----------|-----------|------|------|
| **高** | **高** | **高偏差（High Bias）** / 欠拟合 | 模型过于简单，未能捕捉数据规律 |
| **低** | **高** | **高方差（High Variance）** / 过拟合 | 模型过于复杂，过度记忆训练数据 |
| **高** | **远高于训练集** | **高偏差 + 高方差** | 模型既欠拟合又过拟合（如部分区域拟合不足、部分区域过度拟合） |
| **低** | **低** | **理想状态** | 模型泛化良好 |

> 注：第三行的情况在实际中较少见，通常出现在模型容量极大但训练不充分时。

### 3.5 模型复杂度与正则化

**多项式阶数**和**正则化参数 $\lambda$**对模型的影响：

- **$\lambda$ 过小**：正则化效果弱，容易过拟合（高方差）
- **$\lambda$ 过大**：正则化效果过强，参数被过度压缩，容易欠拟合（高偏差）
- **$\lambda$ 适中**：在偏差和方差之间取得平衡

**Andrew Ng 的建议**：对于神经网络，使用合适的正则化参数 $\lambda$ 基本没有坏处，应优先尝试。

### 3.6 确定性能基线（Baseline）

评估模型前需要确定合理的性能基线，考虑以下三点：
1. **人类水平（Human-level Performance）**：人类在该任务上的表现
2. **竞品水平（Competing Solutions）**：现有算法或商业方案的表现
3. **基于实验的猜测（Educated Guess）**：根据问题难度做出的合理推测

**诊断流程：**
- 若**训练集误差**与基线差距大 → **高偏差**问题
- 若**验证集误差**与训练集误差差距大 → **高方差**问题

### 3.7 学习曲线（Learning Curves）

学习曲线展示了模型性能随训练数据量增加的变化趋势：

- **高偏差（欠拟合）**：增加训练数据量对改善性能**效果不明显**，因为模型本身容量不足
- **高方差（过拟合）**：增加训练数据量通常**有效**，因为更多数据能帮助模型学到更泛化的规律

### 3.8 解决高偏差与高方差的方法

| 修复高偏差（欠拟合） | 修复高方差（过拟合） |
|---------------------|---------------------|
| 增加更多相关特征 | 获取更多训练数据 |
| 增加特征的阶数/复杂度 | 减少特征数量（特征选择） |
| 减小正则化参数 $\lambda$ | **增大**正则化参数 $\lambda$ |
| 增加模型层数/单元数 | 使用 Dropout 等正则化技术 |

### 3.9 神经网络中的偏差与方差

使用神经网络降低偏差和方差的一般流程：

1. 构建一个**足够大的神经网络**（确保低偏差）
2. 观察验证集表现，若存在高方差，则：
   - 增加训练数据
   - 添加正则化（L2、Dropout、数据增强）
3. 回到步骤1迭代，直到训练集和验证集表现都满意
4. 最后在**测试集**上评估

### 3.10 机器学习开发迭代循环

```
选择架构（模型、数据等）
        ↓
    训练模型
        ↓
诊断（偏差、方差、错误分析）
        ↓
[根据诊断结果调整] → 回到第一步
```

### 3.11 错误分析（Error Analysis）

将模型预测错误的样本进行**分类统计**，判断哪些问题值得优先解决：

- 统计各类错误在总错误中的占比
- 优先解决**占比高且可修复**的错误类型
- 对于占比极低的错误，可能不值得投入大量时间

### 3.12 数据增强与数据合成

当获取新数据困难时，可以通过以下方式扩充数据：

**数据变换（Data Augmentation）：**
- 图像：旋转、缩放、镜像翻转、调整亮度/对比度、裁剪
- 音频：添加背景噪声、改变语速/音调、时间拉伸
- 文本：同义词替换、回译、随机插入/删除

**数据合成（Data Synthesis）：**
- 通过计算机图形学、仿真等手段生成全新的训练样本
- 例如：用 3D 渲染引擎生成带标注的合成图像

### 3.13 迁移学习（Transfer Learning）

**定义**：利用来自**不同但相关任务**的数据和已训练模型，提升当前任务的性能。

**标准流程：**

1. **监督预训练（Supervised Pre-training）**
   - 在大规模通用数据集（如 ImageNet、互联网文本）上训练模型
   - 学习通用的低层特征（边缘、纹理、基础语义等）
   - 预训练模型通常可以直接下载使用

2. **微调（Fine-tuning）**
   - 冻结预训练模型的底层参数
   - 使用自己的目标任务数据，训练顶层（或全部）参数
   - 微调时学习率通常比预训练阶段小 10~100 倍

**适用场景：**
- 目标任务数据量小
- 源任务与目标任务具有共享的低层特征
- 希望快速部署且计算资源有限

### 3.14 倾斜数据集的误差指标

当数据集中各类别样本比例严重不均衡时（如疾病检测中阳性样本仅占 1%），**准确率（Accuracy）**会失效（一个全预测阴性的模型也能达到 99% 准确率）。

此时应使用 **精确率（Precision）**和**召回率（Recall）**：

| 指标 | 定义 | 公式 |
|------|------|------|
| **精确率（Precision）** | 预测为正的样本中，实际为正的比例 | $Precision = \frac{TP}{TP + FP}$ |
| **召回率（Recall）** | 实际为正的样本中，被正确预测为正的比例 | $Recall = \frac{TP}{TP + FN}$ |

**其中：**
- **TP（True Positive）**：实际为正，预测为正
- **FP（False Positive）**：实际为负，预测为正（误报）
- **FN（False Negative）**：实际为正，预测为负（漏报）

**阈值对精确率和召回率的影响：**

- **提高阈值**（如从 0.5 提高到 0.8）：
  - 模型更"谨慎"，只有置信度高的才预测为正
  - **精确率 ↑**（减少误报）
  - **召回率 ↓**（增加漏报）

- **降低阈值**（如从 0.5 降低到 0.2）：
  - 模型更"宽松"，更多样本被预测为正
  - **精确率 ↓**（增加误报）
  - **召回率 ↑**（减少漏报）

**F1 分数（F1 Score）：**

为了综合精确率和召回率，使用**调和平均数（Harmonic Mean）**：
$$
F_1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}
$$
$$F_1$$分数在精确率和召回率之间取得平衡，是倾斜数据集上选择阈值和比较模型的常用指标。

## 第四周：决策树

### 4.1 决策树基础结构

决策树由以下节点组成：

- **根节点（Root Node）**：最顶端的节点，包含全部数据
- **决策节点（Decision Node）**：对某个特征进行判断，产生分支
- **叶节点（Leaf Node）**：不再分裂，直接输出预测结果

**核心问题与解答：**

**1. 如何选择决策点？**

对每个特征的所有可能切分点进行遍历，计算切分后**信息增益（Information Gain）**的大小。选择使信息增益最大的特征和切分点作为当前节点的决策规则。信息增益越大，意味着切分后子节点的纯度提升越多。

**2. 如何停止决策（分裂）？**

满足以下任一条件时停止分裂：
- 当前节点所有样本属于同一类别（纯度 100%）
- 信息增益低于预设阈值（继续分裂收益太小）
- 树的深度达到预设最大值（防止过拟合）
- 节点样本数少于最小分裂样本数（防止过拟合）
- 所有特征已用完，无法再切分

### 4.2 熵（Entropy）与信息增益

**熵**用于衡量数据集的**不纯度（Impurity）**或**混乱程度**。熵越高，数据越混乱；熵越低，数据越纯净。

对于二分类问题，设正类比例为 $p_1$，负类比例为 $p_0 = 1 - p_1$：
$$
H(p_1) = -p_1 \log_2(p_1) - p_0 \log_2(p_0)\\
= -p_1 \log_2(p_1) - (1 - p_1) \log_2(1 - p_1)
$$
**熵的性质：**

- 当 $p_1 = 0.5$ 时，熵最大（最混乱），$H = 1$
- 当 $p_1 = 0$ 或 $p_1 = 1$ 时，熵最小（最纯净），$H = 0$

### 4.3 选择最优拆分（Choosing a Split）

对每一个可能的特征和拆分点进行尝试，计算拆分后**熵的减少量**。

**信息增益（Information Gain）**：
$$
IG = H(p_1^{root}) - \left( w^{left} \cdot H(p_1^{left}) + w^{right} \cdot H(p_1^{right}) \right)
$$
其中：
- $H(p_1^{root})$：根节点的熵
- $H(p_1^{left})$、$H(p_1^{right})$：左右子节点的熵
- $w^{left}$、$w^{right}$：左右子节点样本数占总样本数的比例

**选择信息增益最大的拆分方式。**

### 4.4 决策树的构建与停止条件

**递归构建流程：**
1. 计算当前节点的熵
2. 遍历所有特征的所有可能拆分点，计算信息增益
3. 选择信息增益最大的拆分，生成左右子节点
4. 对每个子节点递归执行步骤 1~3

**停止分裂的条件：**
- 节点中所有样本属于同一类别（纯度为 100%）
- 信息增益小于某个阈值
- 树的深度达到预设最大值
- 节点样本数少于最小分裂样本数
- 所有特征已用完

### 4.5 连续值特征与回归树

**连续值特征处理：**
- 对连续特征的所有可能切分点进行排序
- 尝试每一对相邻值的中点作为切分阈值
- 选择信息增益最大的阈值

**回归树（Regression Tree）：**
- 叶节点不再输出类别，而是输出一个连续值（通常是该叶节点内样本目标值的均值）
- 拆分标准从"信息增益"变为**方差减少量**（选择使子节点方差之和最小的拆分方式）

### 4.6 决策树集合方法

**自助采样（Bootstrap Sampling / 有放回采样）：**
从原始数据集中有放回地随机抽取 $N$ 个样本，构建新的训练子集。约 63.2% 的原始样本会被选中，剩余 36.8% 的样本作为**袋外样本（Out-of-Bag, OOB）**可用于验证。

**随机森林（Random Forest）：**
1. 通过 Bootstrap 生成多个训练子集
2. 对每个子集训练一棵决策树
3. 在每次分裂时，随机选取一部分特征作为候选
4. 最终预测：分类任务投票，回归任务取平均

**XGBoost（eXtreme Gradient Boosting）：**
- 一种高效的梯度提升决策树算法
- 串行训练：每棵新树专门学习前面所有树的**残差（Residual）**
- 通过梯度下降优化，加入正则化防止过拟合
- 在结构化数据竞赛中表现优异

### 4.7 模型选择指南：决策树 vs 神经网络

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| **结构化数据**（表格数据） | **决策树 / 随机森林 / XGBoost** | 特征关系明确，树模型可解释性强，训练快 |
| **非结构化数据**（图像、音频、文本） | **神经网络** | 需要自动提取层次化特征，树模型难以处理高维原始输入 |
| **追求训练与推理速度** | **决策树** | 单次预测只需若干次比较，速度极快 |
| **数据量极大且追求最高精度** | **神经网络** | 容量大，配合正则化和大数据能达 SOTA |
| **需要迁移学习** | **神经网络** | 预训练权重可跨任务复用 |
| **需要强可解释性** | **决策树** | 决策路径透明，易于向非技术人员解释 |
| **多模型融合/集成** | **两者皆可** | 神经网络做特征提取 + 树模型做最终分类也是常见方案 |
